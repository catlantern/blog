## 🔥 高危漏洞预警

> **标题**：微软 Azure Cosmos DB Gremlin API 高危漏洞险致全部数据库遭入侵
> **来源**：腾讯新闻（援引 Wiz 披露）
> **发布时间**：2026-08-06
> **摘要**：谷歌旗下安全子公司 Wiz 在 Azure Cosmos DB 的 Gremlin API 中发现高危漏洞，若被攻击者抢先利用，可窃取"Cosmos 主密钥"，进而获得对任意 Cosmos 数据库账户的读写权限，并获取订阅 ID、租户 ID 等敏感标识。微软已于 2025 年 11 月收到漏洞详情，两天内部署热修复，随后耗时约 8 个月完成基础架构重构，彻底移除 Cosmos 主密钥并引入新防护机制。该漏洞波及范围涵盖客户数据库及微软自身数据库，风险极高。
> **链接**：https://news.qq.com/rain/a/20260806A06HI700
> **标签**：`#Microsoft` `#AzureCosmosDB` `#高危漏洞` `#Wiz`

## ⚠️ 今日重点关注

**1. 微软 Azure Cosmos DB Gremlin API 高危漏洞风险**
- **攻击复杂度**：中高；需竞速于厂商修复窗口提前利用，但对已获取主密钥的攻击者而言利用门槛低。
- **影响范围估算**：极高；波及 Azure Cosmos DB 全部 NoSQL 数据库，包括客户数据库及微软自身数据库，可获取任意账户读写权限与订阅、租户 ID 等敏感信息。
- **建议优先级**：高，云服务与数据库用户应核查租户密钥轮换、访问控制与日志审计，关注微软官方修复披露。
- **相关联历史事件**：2021 年 Wiz 曾披露 Cosmos DB 数据探索工具 Jupyter Notebook 中可访问数据库密钥的漏洞。

**2. Open VSX 平台 77 款山寨插件供应链攻击**
- **攻击复杂度**：低；攻击者批量复制正版插件名称与说明并上传低版本号套件即可完成伪装。
- **影响范围估算**：中高；Open VSX 被大量基于 VS Code 的开发工具使用，可波及开发人员本地环境及企业软件开发流程，19 款携带完整信息窃取载荷。
- **建议优先级**：高，开发者应核验插件来源与命名空间、避免安装低版本号套件，企业应审计开发环境第三方扩展。
- **相关联历史事件**：本次 77 款插件均连接同一新注册域名 mangorbit[.]com，研判为同一黑客批量炮制。

**3. Snowflake 大规模数据泄露案认罪，暴露凭据管理顽疾**
- **攻击复杂度**：低；攻击并非利用漏洞，而是基于多年未轮换、未启用 MFA 的被盗凭据。
- **影响范围估算**：极大；波及至少 165 家机构、暴露超 1 亿人记录，攻击者个人获利至少 49.5 万美元。
- **建议优先级**：高，各组织应强制启用多因素认证、轮换历史凭据并部署信息窃取恶意软件检测。
- **相关联历史事件**：Mandiant 将相关行为者标记为 UNC5537，其处理事件均可追溯至信息窃取程序的各类凭据，部分凭据自 2020 年 11 月起即遭窃取。

**4. 网络安全审查办公室对派拓公司在华产品启动审查**
- **攻击复杂度**：不涉及攻击能力评估，属国家级合规审查程序。
- **影响范围估算**：中；直接关系到 Pala Alto Networks 在华销售网络防火墙等产品的可用性与合规存续，进而影响关键信息基础设施供应链。
- **建议优先级**：中高，在审单位及用户应跟踪审查进展并准备替代方案，关注合规动态。
- **相关联历史事件**：依据《网络安全审查办法》开展，此前已有多起针对美方实体及在华销售产品的管制反制动作。

**5. 《网络数据安全风险评估办法》将于 8 月 20 日起施行**
- **攻击复杂度**：不适用；属制度合规要求而非攻击事件。
- **影响范围估算**：高；覆盖境内开展网络数据安全风险评估活动的各类主体，规范评估活动、完善数据安全管理机制。
- **建议优先级**：高，数据处理者应提前梳理数据资产、完善风险评估流程与报告机制，避免逾期整改。
- **相关联历史事件**：国家网信办等三部门联合发布，配套公布答记者问及多篇权威解读。

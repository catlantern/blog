## ⚠️ 今日重点关注

**1. Windows Defender 零日漏洞 ShieldBreak 公开，可绕过 7 月补丁完全控制设备**
- **攻击复杂度**：中高，公开了 POC 验证代码，攻击者无需物理接触即可利用，但需已存在一定本地执行或远程入口。
- **影响范围估算**：影响现行 Windows 11 25H2、Windows Server 2025 及已停更的 Windows 10；官方尚未确认修复时间，存在被武器化的风险。
- **建议优先级**：极高。建议企业安全团队立即评估 Defender 引擎版本并部署缓解措施，持续关注微软官方修复动态，避免运行不可信 POC，同时加强端点检测与响应。
- **相关联历史事件**：与该研究员此前披露的 RoguePlanet（CVE-2026-50656）及 YellowKey 漏洞同属针对微软 Windows 安全机制的持续对抗。

**2. Cl0p 借 PTC 漏洞展开大规模供应链攻击，波及壳牌、飞利浦等近 50 家企业**
- **攻击复杂度**：较低。漏洞 CVE-2026-12569 已被 CISA 确认在野利用，Cl0p 采用批量扫描互联网暴露实例的方式，攻击门槛低。
- **影响范围估算**：涉及工程设计、生产制造与能源等行业的近 50 家全球大型企业，含壳牌、飞利浦、通用电气、费哲等。
- **建议优先级**：高。使用 PTC Windchill/FlexPLM 的企业应立即核查补丁与入侵痕迹，排查互联网暴露面，实施漏洞修复与日志审计。
- **相关联历史事件**：延续 Cl0p 一贯利用主流软件套件零日漏洞的攻击模式，与 2021 年 ProxyLogon 等大规模 Exchange 攻击在手法上高度相似。

**3. 微软八月补丁 KB5121003 修复 421 个漏洞，官方敦促 3 天内安装**
- **攻击复杂度**：修复补丁本身为主，涉及 37 个远程代码执行漏洞与 5 个提权漏洞，存在被组合利用的可能。
- **影响范围估算**：覆盖 Windows 11 全系（25H2/24H2）及关联的 Office、Teams、Edge 产品。
- **建议优先级**：极高。建议用户与运维人员尽快完成补丁安装（最多两次重启），并核对版本号 Build 26200.9168 / 26100.9168，避免中断更新。

- 美国 CISA 将七个已遭利用漏洞纳入“已知被利用漏洞（KEV）”目录，其中 SonicWall SMA 1000 系列设备的 SSRF 漏洞 CVE-2026-83548 评分为满分 10.0，攻击者已用于部署反向 Shell 与挖矿程序。

## ⚠️ 今日重点关注

**1. SonicWall SMA 1000 满分漏洞（CVE-2026-83548）已被在野利用并纳入 KEV 目录**
- **攻击复杂度**：低——漏洞属服务端请求伪造类型，远程未认证攻击者无需任何凭据即可触达目标系统，CVSS 评分为满分 10.0。
- **影响范围估算**：主要波及部署 SonicWall SMA 1000 系列安全网关设备的政企边界网络；攻击者已利用其部署反向 Shell 与加密货币挖矿程序，设备安全性与可用性均受威胁。
- **建议优先级**：高——建议立即核查相关资产是否受该系统影响，尽快应用厂商安全补丁，并在补丁落地前临时收敛管理面暴露、加装访问控制与边界检测。
- **相关联历史事件**：属于 CISA 每周新增“已知被利用漏洞（KEV）”的一批七项漏洞之一，反映网络边界设备成为攻击者规模化投放持久化后门与挖矿载荷的高价值目标。

**2. 韩国流媒体平台 Tving 约 3954 万个账号信息被窃**
- **攻击复杂度**：中等——攻击者通过窃取一名开发人员的访问密钥后入侵 Tving 内部系统，属于典型的凭证窃取加后门利用结合路径。
- **影响范围估算**：涉及约 3954 万个账号及 361 项技术资产（含源代码），覆盖活跃、休眠及已注销账户，泄露信息含姓名、出生日期、手机号码、邮箱等 20 个大类共 70 项数据。
- **建议优先级**：高——受影响的韩国及跨境用户应警惕针对性的短信钓鱼、语音诈骗等次生犯罪；监管层面则关注延迟 24 小时上报制度可能带来的处罚。
- **相关联历史事件**：继本地多家企业数据泄露后，Tving 事件成为韩国互联网史上罕见的大规模个人信息泄露案例，凸显关键网络平台在凭证管理与监管上报合规方面的短板。

**3. FBI 调查疑似上亿份美加驾照等证件在暗网样本被售事件**
- **攻击复杂度**：尚在评估中——FBI 已确认介入调查，但数据具体来源与泄露渠道尚未查明，涉事暗网站点在被曝光后已下线。
- **影响范围估算**：若属实，涉及超过 1.53 亿份美国与加拿大驾照、数百万张其他身份证件、旅行证件及数十万份医疗记录，或将创下北美史上最大规模政府签发证件泄露纪录。
- **建议优先级**：高——涉及个人身份与政府签发证件，一旦确认将带来大规模身份盗用与金融诈骗风险，也构成对敏感岗位人员（含政要）的国家安全威胁。
- **相关联历史事件**：该事件由知名安全记者 Brian Krebs 于 9 月 1 日率先披露，并通过本人驾照及多名当事人核实数据真实性，反映暗网规模化售卖政府签发证件已成为常态化威胁。

**4. “Sorry”勒索病毒集中攻击境内 Linux Web 服务器**
- **攻击复杂度**：中高——攻击者利用 WebPros cPanel 授权问题漏洞获取服务器管理权限，再将勒索程序伪装为常见 sshd 进程运行。
- **影响范围估算**：主要波及暴露于互联网的境内 Linux Web 服务器运维者；病毒会终止数据库、安全防护与备份服务，批量窃取数据并加密文件（后缀“.sorry”），并通过 SSH 弱口令横向扩散。
- **建议优先级**：高——关键动作是抢在“加密”发生前完成防护升级，及时修补 cPanel 授权相关漏洞、收紧授权账户权限并加强 SSH 口令与配置审计。
- **相关联历史事件**：国家计算机病毒应急处理中心已就此向境内发布预警，揭示勒索攻击正从终端向服务器、从单机感染向业务数据窃取链条转变的新趋势。

**5. 微软将收紧 Windows 驱动签名并引入 SBOM/VEX 强制要求**
- **攻击复杂度**：不适用（此为供应链与代码合规政策层面调整）。
- **影响范围估算**：面向 Windows 11 25H2、26H1 及 Windows Server 2025 及后续版本提交驱动签名认证的全体软硬件开发商；SBOM 与 VEX 文件需符合 SPDX 3.0 格式并经 COSE 签名。
- **建议优先级**：中——建议相关供应链开发与合规团队提前梳理驱动二进制中的三方与开源组件，为 2027 年 3 月正式生效的新窗口做好准备。
- **相关联历史事件**：该要求同时呼应欧盟《网络韧性法案》对软件物料清单与漏洞信息交换的合规压力，与近年来全球推动供应链安全与软件清单透明化的监管趋势一脉相承。

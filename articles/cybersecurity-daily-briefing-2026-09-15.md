> **标题**：Microsoft Edge 多个漏洞高危保安警报（含在野利用的远程代码执行漏洞 CVE-2026-87491）
> **来源**：香港政府电脑保安事故协调中心（GovCERT.HK）
> **发布时间**：2026-09-14
> **摘要**：香港政府电脑保安事故协调中心发布高危保安警报（编号A26-09-22），指微软发布安全性更新以应对 Microsoft Edge 的多个漏洞。远程攻击者可诱使用户用存在漏洞的浏览器打开含特制内容的网页发起攻击。通报指出，一个远程代码执行漏洞（CVE-2026-87491）正受到攻击。受影响版本为 Microsoft Edge 153.0.4234.32 之前版本，成功利用可导致远程代码执行、拒绝服务、权限提升、信息泄露、绕过安全限制、仿冒欺骗或篡改。建议管理员与用户尽快升级至 153.0.4234.32 或更高版本。

> **标签**：`#Microsoft` `#Edge` `#CVE-2026-87491` `#漏洞预警`

## ⚠️ 今日重点关注

**1. Microsoft Edge 远程代码执行漏洞 CVE-2026-87491 被指正遭在野利用**
- **攻击复杂度**：中低，攻击者仅需诱导用户访问含特制内容的网页即可触发，无需身份认证或本地权限。
- **影响范围估算**：所有低于 153.0.4234.32 版本的 Microsoft Edge 用户，覆盖个人终端与企业办公终端。
- **建议优先级**：最高。应立即核查 Edge 版本并升级至 153.0.4234.32 或更高版本，同时排查是否存在异常访问与可疑下载行为。
- **相关联历史事件**：GovCERT.HK 高危保安警报 A26-09-22；微软 Edge 9月安全更新中批量修复的多个漏洞（含 CVE-2026-76017 至 CVE-2026-76019、CVE-2026-76021 至 CVE-2026-76023、CVE-2026-76036、CVE-2026-76039、CVE-2026-77490）。

**2. 9月 Windows 安全更新 KB5124008 引发远程桌面服务故障与 AMD 平台驱动崩溃**
- **攻击复杂度**：不涉及外部攻击者，属补丁引入的可用性回归问题，触发条件为安装指定更新。
- **影响范围估算**：覆盖 Windows 11 的 26H1、25H2、24H2、23H2，Windows 10 的 22H2、21H2 及 Enterprise LTSC 2019/2016，服务器端涵盖 Windows Server 2025、2022、2019、2016、2012 R2 与 2012；另叠加部分 AMD 平台显卡驱动崩溃反馈。
- **建议优先级**：高。企业 IT 应优先评估远程桌面依赖度较高业务系统的补丁部署节奏，必要时暂缓推送并关注微软后续修复与已知问题回滚机制。
- **相关联历史事件**：微软9月11日更新 Windows 健康控制台确认问题；社区反馈 KB5126052（.NET 更新）同期引发驱动超时。

**3. 《人工智能安全治理框架》3.0 发布，AI 安全治理进入新阶段**
- **攻击复杂度**：非直接攻击事件，但涉及 AI 应用的模型滥用、数据投毒、算法滥用等新型风险应对。
- **影响范围估算**：面向全部人工智能服务提供者与使用者，重点覆盖关键信息基础设施、政务、金融、教育等高敏感场景。
- **建议优先级**：高。相关单位应对照框架梳理模型风险分类、技术应对与综合治理措施，完善 AI 应用的准入、评估与审计机制。
- **相关联历史事件**：2024年《人工智能安全治理框架》1.0、2025年《人工智能安全治理框架》2.0；2026年国家网信办公布7月至8月新增124款生成式人工智能服务备案。

**4. 工信部“人工智能+软件”方案落地，AI 生成代码与智能体身份管控成新增安全需求**
- **攻击复杂度**：中高，涉及智能编程工具生成的代码缺陷、智能体身份冒用与行为越权、供应链开源代码风险等复合型攻击面。
- **影响范围估算**：目标覆盖2万家规模以上软件企业，并延伸至制造、政务、金融等重点行业的智能体软件标杆应用。
- **建议优先级**：高。软件企业应在开发环节落实代码安全审查与漏洞挖掘，在产品环节落实行为可控、全程可溯，并提前建立智能体身份与权限管控体系。
- **相关联历史事件**：2026年9月11日工信部对外发布该实施方案；9月14日国家网络安全宣传周发布2026年人工智能技术赋能网络安全应用测试结果。

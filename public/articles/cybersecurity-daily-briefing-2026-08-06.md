# 网络安全资讯日报 – 2026-08-06

**本期要点**：

- 香港政府计算机保安事故协调中心发布多起高危漏洞警报，其中 Apache Tomcat 信息泄露漏洞（CVE-2026-34486）已被报告在野利用，F5 产品曝出多项安全缺陷。
- 微软披露黑客组织 Storm-2945（归属 APT29）针对全球酒店公共 Wi-Fi 的攻击活动，通过钓鱼认证页面窃取旅客凭据并投放木马。

- 房地产开发商 Bonava 确认遭遇数据泄露，客户姓名、地址等个人数据被非法访问，已通报数据保护机构并报案。

## 🔥 高危漏洞预警

> **标题**：Apache Tomcat 多漏洞告警 信息泄露漏洞已在野利用（CVE-2026-34486）
> **来源**：GovCERT.HK（香港政府计算机保安事故协调中心）
> **发布时间**：2026-08-05
> **摘要**：Apache 软件基金会发布安全更新修复 Apache Tomcat 的多个漏洞。报告显示信息泄露漏洞 CVE-2026-34486 已被在野利用，远程攻击者可通过发送特制请求利用相关缺陷。受影响版本覆盖 Tomcat 9.0.13 至 9.0.116、10.1.0-M1 至 10.1.53 以及 11.0.0-M1 至 11.0.20。官方建议系统管理员立即修补受影响系统以缓解被攻击风险。

> **标题**：F5 多款产品曝出安全漏洞 可致拒绝服务或安全限制绕过
> **来源**：GovCERT.HK（香港政府计算机保安事故协调中心）
> **发布时间**：2026-08-05

## ⚠️ 今日重点关注

**1. Apache Tomcat 信息泄露漏洞（CVE-2026-34486）在野利用**
- **攻击复杂度**：低，远程攻击者可通过发送特制请求利用，无需高权限。
- **影响范围估算**：影响 Tomcat 9.0.13 至 9.0.116、10.1.0-M1 至 10.1.53、11.0.0-M1 至 11.0.20 三大版本线，覆盖面广，建议尽快评估资产暴露面。
- **建议优先级**：高，官方已确认在野利用，应立即打补丁并核查是否遭入侵。
- **相关联历史事件**：Apache Tomcat 曾多次曝出信息泄露与反序列化等高危漏洞，属被攻击者高频利用的中间件目标。

**2. 微软披露 Storm-2945 针对酒店公共 Wi-Fi 的攻击活动**
- **攻击复杂度**：中低，攻击者先行攻陷酒店网络基础设施，再篡改 DNS 与 HTTP 流量实施钓鱼。
- **影响范围估算**：全球范围内酒店及会议场所公共 Wi-Fi 用户，活动自 2026 年 5 月起持续至今，影响范围广。
- **建议优先级**：高，旅客及企业用户应将公共 Wi-Fi 视为不可信网络，优先使用移动数据与个人热点。
- **相关联历史事件**：Midnight Blizzard（APT29）为长期活跃的国家级对手，此前多次针对云、政府及能源领域。

**3. 美国多州供水系统遭疑似网络攻击**
- **攻击复杂度**：中，攻击者疑似以伊朗为背景实施，涉及关键基础设施定向打击。
- **影响范围估算**：至少十余个州报告事件，部分活动已削弱供水运营，影响面涉及民生关键设施。
- **建议优先级**：高，供水企业应落实断网隔离与手动控制预案，强化 OT 网段防护。
- **相关联历史事件**：美国供水系统近年来多次遭国内黑客及外国背景组织攻击，伊朗此前亦被指针对美国水坝开展网络活动。

**4. 列支敦士登实益所有人登记系统遭入侵致 3.1 万实体数据外泄**
- **攻击复杂度**：高，官方称系针对高度复杂安全架构的、技术性极强的定向攻击。
- **影响范围估算**：约 3.1 万家法人实体，含实益所有人姓名、出生日期、国籍、居住国等敏感信息。
- **建议优先级**：中高，涉及反洗钱与金融监管数据，建议相关金融机构与涉事主体关注身份冒用风险。
- **相关联历史事件**：列支敦士登为国际财富管理重镇，实益所有人登记的设立本为打击洗钱，此次遭袭凸显金融监管数据安全挑战。

**5. 数据中心沦为美伊冲突物理打击目标**
- **攻击复杂度**：不适用传统网络攻击复杂度衡量，为军事层面的物理打击。
- **影响范围估算**：海湾地区至少五座数据中心遭袭，亚马逊、谷歌、微软等云基础设施承载美军 AI 系统，影响波及军事与商业。
- **建议优先级**：中高，企业应重新评估中东地区数字基础设施布局风险，强化容灾与多云冗余。
- **相关联历史事件**：伊朗此前多次以网络攻击回应美国制裁，2026 年战事将目标从网络扩展至物理摧毁数据中心，属首开先河。
